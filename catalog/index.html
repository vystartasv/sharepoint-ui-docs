Component catalog

Component catalog

Section titled “Component catalog”

Browse the complete component set in the sidebar, or search the component names, API signatures, callbacks, slots, and summaries. Each visual component page includes a live preview with appearance and accent controls. Context providers and hooks link to their related rendered component.

  • AccordionItem — Identify one panel by value; compose an accessible AccordionHeader and AccordionPanel, or use the heading/default-content compatibility form.
  • AccordionHeader — Compose the labelled, keyboard-operable heading for an AccordionItem with optional leading and expandable icon slots.
  • AccordionPanel — Compose a region-labelled content panel controlled by its parent AccordionItem.
  • Accordion — Group composed sections with controlled or default values, single/multiple and collapsible behavior, change details, and optional linear/circular keyboard navigation.
  • AccordionProvider — Provide controlled open items and accordion interaction defaults to composed Accordion descendants.
  • Alert — Announce by intent with polite or assertive live-region behavior, and compose icon, avatar, action, or dismissal slots.
  • Avatar — Identify a person or entity with initials, an image, or composed icon and badge slots.
  • AvatarGroupProvider — Provide shared avatar size, layout, and overflow context to avatar group descendants.
  • AvatarGroup — Stack people avatars compactly and reveal the remaining members with a localized, keyboard-operable overflow control.
  • AvatarGroupItem — Represent one named person in an AvatarGroup, inheriting the group size and expanding to a labelled row inside its overflow popover.
  • AvatarGroupPopover — Show overflow members in a theme-aware, labelled popover with a count or icon trigger and keyboard dismissal.
  • Badge — Show a compact status or category label alongside its related content.
  • CounterBadge — Display an accessible count or dot badge with an optional overflow limit.
  • PresenceBadge — Show a compact, accessible presence status with an optional out-of-office marker.
  • Breadcrumb — Show the current location in a labelled navigation trail with a replaceable list root and optional arrow-key focus.
  • BreadcrumbItem — Represent a destination or current location inside a Breadcrumb.
  • BreadcrumbButton — Render a theme-aware breadcrumb action as a button or link with current and disabled states.
  • BreadcrumbDivider — Provide an accessible visual separator between breadcrumb items.
  • Button — Render a native button or accessible link/action anchor with context-inherited sizing, automatic icon-only layout, and the active SharePoint accent.
  • ToolbarButton — Toolbar command button with a subtle appearance and medium size by default.
  • ButtonGroup — Group related buttons under one accessible label, with horizontal or vertical layout and native button tab behavior.
  • MenuButton — A themed menu trigger that composes with Menu for open state, keyboard focus, and dismissal.
  • CompoundButton — Present a primary action with a descriptive second line and optional decorative icon.
  • ToggleButton — A button with an accessible pressed state, controlled or uncontrolled operation, and theme-derived selected styling.
  • SplitButton — Pair a primary action with a localized menu trigger; replace either button slot with a React element or partial prop object while retaining composed Menu behavior.
  • ToolbarToggleButton — Toggle toolbar command with the library ToggleButton pressed state and subtle appearance by default.
  • Card — Group related content in a themed surface with filled, outline, subtle, and alternative appearances plus compact, medium, large, and horizontal layouts. Selectable cards provide a themed, keyboard-operable checkbox with controlled or default selection. Nonselectable cards support off, no-tab, tab-exit, and tab-only focus modes. SharePointCard remains available as an alias.
  • CardHeader — Compose a card identity, title, supporting description, and optional action in a responsive logical-direction header.
  • CardFooter — Arrange related card actions in a wrapping footer, with an optional action aligned to the logical end.
  • CardPreview — Show an edge-to-edge image, video, or custom SharePoint preview with an optional theme-aware logo overlay.
  • Carousel — Compose direct or grouped CarouselCard slides with localized navigation, optional autoplay, numeric or responsive page groups, drag interaction, and theme-aware motion.
  • CarouselCard — Represent one accessible carousel slide, with optional intrinsic sizing for content-driven galleries.
  • CarouselNav — Group carousel position buttons with RTL-aware roving keyboard focus.
  • CarouselNavButton — Jump to a carousel slide with selected state and roving focus.
  • CarouselNavImageButton — Navigate carousel slides with an accessible image preview.
  • CarouselButton — Add a previous or next action to a composed Carousel control strip; the Carousel owns bounds, wrapping, and disabled state.
  • CarouselAutoplayButton — Expose a localized, accessible play/pause control synchronized with its parent Carousel autoplay state.
  • CarouselNavContainer — Arrange Carousel navigation, previous/next, and autoplay controls in inline or overlay layouts.
  • CarouselSlider — Provide the scroll track and optional arrow-key focus group for CarouselCard slides.
  • CarouselViewport — Mark the visible slide region in a composed Carousel; the parent Carousel manages scrolling and pauses autoplay during focus or pointer interaction.
  • CarouselProvider — Provide Carousel state and navigation methods to React descendants through the Carousel context.
  • ColorPicker — Choose a color with controlled HSV or HEX values, interactive saturation/brightness and hue controls, opacity, HEX/RGB entry, and theme-derived swatches.
  • ColorArea — Provide an accessible saturation and brightness surface inside ColorPicker or as a standalone HSV-controlled control.
  • ColorSlider — Adjust hue, saturation, or value inside ColorPicker or as a standalone HSV-controlled slider.
  • AlphaSlider — Adjust opacity or transparency inside ColorPicker or as a standalone HSV-controlled slider.
  • ComboBox — Filter and select one or multiple options with accessible checks, visible removable tags, and form-associated values; mount the listbox popup elsewhere without moving the input.
  • ComboOption — Define one selectable or disabled suggestion inside a ComboBox.
  • ComboboxProvider — Share Fluent-compatible option registration, selection, active-option, appearance, and open state with composed combobox descendants; custom value and callback fields remain supported.
  • Dropdown — Choose from grouped options with a button trigger, replaceable button and listbox roots, controlled or default selection, keyboard interaction, accessible listbox semantics, and mountNode popup targeting.
  • Listbox — Render a standalone single or multiselect listbox with Fluent menu semantics for multiselect, keyboard active-descendant navigation, root refs, and Option composition.
  • Option — Declare a selectable option for Dropdown, ComboBox, or standalone Listbox.
  • OptionGroup — Group related options and expose the group label to assistive technology.
  • DataGrid — Use a virtualized data/columns API or compose accessible grid parts with local or indexed async data, bounded row rendering, selection, resizing, editing, and custom layouts.
  • DataGridHeader — Group composable DataGrid header rows with grid semantics.
  • DataGridBody — Render windowed item rows, accessible provider group rows, and loading placeholders in the composed DataGrid context.
  • DataGridRow — Compose a grid row and expose renderCell/renderHeaderCell helpers to its children; supports Fluent cell, row, and composite focus modes.
  • DataGridHeaderCell — Render a sortable, keyboard-navigable DataGrid column header.
  • DataGridCell — Render a grid cell with roving focus, nested-control group focus, or optional validated editing.
  • DataGridSelectionCell — Provide row or select-all checkboxes wired to the composed DataGrid selection state.
  • DataGridContextProvider — Provide items, columns, selection, sorting, and roving focus state to composed DataGrid parts.
  • ColumnIdContextProvider — Pass the current table column id to DataGrid header and cell components.
  • DatePicker — Select localized dates using a keyboard-accessible calendar with RTL navigation, min/max constraints, and native form participation.
  • Dialog — Present a focused modal or non-modal task surface with title, actions, and dismissal controls.
  • DialogSurface — Compose the visible surface inside the native accessible dialog element.
  • DialogTitle — Render the dialog heading and provide its accessible name, with an optional trailing action.
  • DialogContent — Group the dialog’s body and action content.
  • DialogBody — Render dialog content with standard spacing and readable line height.
  • DialogActions — Align dialog actions consistently at the end of a composed dialog.
  • DialogTrigger — Open the parent dialog when its slotted interactive child is activated.
  • Divider — Separate adjacent content groups without creating an extra layout container.
  • Drawer — Present a modal or non-modal task surface with optional full-screen expansion.
  • InlineDrawer — Show a non-modal drawer in the page layout with optional separator, title, navigation, and actions.
  • OverlayDrawer — Use the modal or non-modal overlay drawer with Fluent overlay defaults.
  • DrawerFooter — Place secondary actions in the drawer’s logical-end footer region.
  • DrawerBody — Wrap the main drawer content while preserving the drawer’s scroll and layout behavior.
  • DrawerHeaderTitle — Provide the title text and optional header action for a Drawer.
  • DrawerHeaderNavigation — Add labelled navigation or a back action to the drawer header.
  • DrawerHeader — Group drawer header navigation, title, and title actions without adding a wrapper that would break named slots.
  • TextField — Edit a single-line value with an accessible label and controlled change events.
  • Field — Compose one form control with a visible label, helper text, required state, and theme-aware validation feedback.
  • FileUpload — Select files by browsing or drag and drop, enforce type/count/size constraints, expose accessible removal and events, and contribute selected files to native forms. The consumer owns upload transport and SharePoint persistence.
  • Image — Render a native image with HTMLImageElement ref forwarding, responsive loading, Fluent fit defaults, shape, border, and shadow options.
  • InfoLabel — Pair a form label with accessible supplementary guidance without putting the help button inside the clickable label.
  • InfoButton — Open a keyboard-operable, theme-aware information popover with support for links and other focusable guidance.
  • Input — A bare native input with controlled/default values, Fluent size and appearance variants, before/after content slots, input/change events, and native form validation. Supply aria-label or aria-labelledby; use TextField when a shadow-safe visible label is needed.
  • Label — Label a form control with native association, optional required marker, and theme-aware sizing.
  • Link — Navigate with an anchor or render an accessible button or span action when needed.
  • List — Compose a keyboard-navigable list with single or multiple selection.
  • ListItem — Provide a selectable, navigable, actionable row within List.
  • ContextMenu — Open a Menu at a pointer or trigger edge with right-click, the Context Menu key, or Shift+F10.
  • Menu — Offer a trigger-anchored command list with keyboard navigation, typeahead, nested submenus, dismissal, and optional popup mounting elsewhere.
  • MenuItem — Provide an enabled, disabled, checkbox, or radio command inside a Menu.
  • MenuItemCheckbox — Render a selectable menu checkbox with controlled group values and persistent checked state.
  • MenuItemRadio — Render a menu radio choice grouped by its name value.
  • MenuItemSwitch — Render a menu checkbox with a switch indicator for an immediate setting.
  • MenuItemLink — Navigate from a menu item using a native anchor with disabled link semantics.
  • MenuList — Compose menu items and optionally control their checked values and alignment hints.
  • MenuPopover — Wrap and style the menu content surface in a composable Menu.
  • MenuSplitGroup — Group two menu actions as a horizontal or vertical split action.
  • MenuTrigger — Mark the trigger in a compound Menu composition and provide an accessible custom-element trigger.
  • MenuBar — Group top-level command menus with a labelled menubar, roving focus, and direction-aware keyboard navigation.
  • MenuBarItem — Render a top-level MenuBar command with accessible menu-trigger state and roving tab focus.
  • MenuDivider — Separate related command groups within a Menu.
  • MenuGroup — Label and group related Menu items for assistive technology.
  • MenuGroupHeader — Display a non-interactive visual heading within a Menu.
  • MessageBar — Present an accessible named status group, announce body and action changes at polite or assertive urgency, and adapt automatically between singleline and multiline layouts.
  • MessageBarActions — Compose message actions with a separate trailing container action slot.
  • MessageBarBody — Provide the descriptive content region within a message bar.
  • MessageBarGroup — Group related messages with consistent spacing and optional entry motion.
  • MessageBarTitle — Add a concise title to the message bar.
  • Nav — Navigate app destinations with grouped disclosures, a responsive localized mobile drawer, and an optional compact desktop rail that retains screen-reader labels.
  • NavItem — Render a selectable navigation destination as a native link or button.
  • NavCategory — Group expandable navigation destinations.
  • NavCategoryItem — Provide the accessible disclosure button for a NavCategory.
  • NavSubItemGroup — Contain the destinations revealed by a NavCategory.
  • NavSubItem — Render a nested destination as a native link or button.
  • NavDivider — Separate navigation groups.
  • NavSectionHeader — Label a group of related navigation items.
  • AppItem — AppItem is a selectable application destination with icon/avatar and native link semantics.
  • AppItemStatic — Display the current application identity without navigation behavior.
  • Hamburger — Accessible keyboard-operable navigation toggle control.
  • NavDrawer — Compose Nav with optional drawer header, body, and footer regions.
  • NavDrawerBody — Group the main navigation drawer content.
  • NavDrawerFooter — Place secondary actions at the end of the navigation drawer.
  • NavDrawerHeader — Place title and controls at the start of the navigation drawer.
  • SplitNavItem — Combine a destination with a separate secondary action.
  • Overflow — Keep priority actions visible as space changes and render the overflowed actions through the existing Menu primitives without cloning or moving controls.
  • OverflowProvider — Provide overflow state and registration helpers to compound item, divider, and menu hooks.
  • useOverflowSnapshot — Subscribe to a selected value from the latest overflow snapshot.
  • OverflowItem — Register one stable action with the responsive overflow engine; pin essential actions and provide its MenuItem representation for narrow layouts.
  • OverflowDivider — Visually separate action groups and hide the divider when its group moves into overflow.
  • OverflowReorderObserver — Fluent-compatible renderless marker; the local overflow engine already observes child-list changes automatically.
  • Persona — Present a person with an Avatar, four composable identity text lines, and localized presence context.
  • Popover — Show a non-modal top-layer surface anchored to a trigger, with optional mountNode portal targeting, dismissal, focus return, and Fluent positioning fallbacks, boundaries, offsets, sizing, virtual targets, and update refs.
  • PopoverProvider — Supply controlled open state, interaction settings, appearance, sizing, and an optional mountNode to a composed Popover.
  • PopoverTrigger — Provide a composable trigger slot for Popover; the actual button or link retains its native interaction.
  • PopoverSurface — Group and style composed Popover content inside the collision-aware top-layer surface.
  • ProgressBar — Report determinate or indeterminate task progress with theme-aware Fluent colors, shapes, thicknesses, reduced-motion support, and accessible progressbar semantics.
  • RadioGroup — Choose one value from related radio options with controlled or default state, stacked or horizontal layout, native form participation, validity, reset, and keyboard behavior.
  • Radio — Define one labelled RadioGroup option with its own label position, disabled state, and selection callback.
  • Rating — Choose a whole-step or half-step score using accessible radio controls.
  • RatingDisplay — Display an accessible, theme-aware whole or fractional rating with compact and count modes.
  • RatingItem — Compose a reusable filled or outlined rating item inside RatingDisplay.
  • RichTextEditor — Edit sanitized rich HTML with controlled or uncontrolled form values, accessible formatting history, table editing, and application-managed durable image upload for SharePoint persistence.
  • SearchBox — Search or filter content with a clear action, native form value, and Enter-to-submit behavior.
  • Select — Choose a value from a fixed native option list with browser keyboard behavior, configurable native focus, and tab order.
  • Skeleton — Show the shape of pending content while honoring reduced motion and forced colors.
  • SkeletonItem — Render a themed loading placeholder with Fluent size, shape, appearance, and motion options.
  • Slider — Choose a numeric value within a range using pointer or keyboard input.
  • SpinButton — Edit a bounded numeric value with increment and decrement controls.
  • Spinner — Show indeterminate progress in eight sizes, primary or inverted appearance, four label positions, optional delayed display, and a provider-controlled default size.
  • SwatchPicker — Render accessible color and image swatches as a keyboard-operable single- or multi-selection grid or row.
  • ColorSwatch — Represent one selectable color with an accessible name and selected state.
  • ImageSwatch — Represent one selectable image or texture swatch with a caller-provided accessible name.
  • EmptySwatch — Offer an accessible add-color action within a swatch set.
  • SwatchPickerRow — Group swatches into an explicit visual and semantic row within a picker.
  • Table — Render a responsive, theme-aware table surface with small, medium, and large density plus an optional flex-based non-native layout.
  • TableHeader — Group column headers with table semantics.
  • TableBody — Group table body rows with table semantics.
  • TableRow — Render a themed table row with an optional selected appearance.
  • TableHeaderCell — Render a column header with accessible sort state and a sort request event.
  • TableCell — Render a semantic table data cell.
  • TableCellLayout — Arrange primary or truncated content inside a table cell.
  • TableCellActions — Reveal contextual row actions on hover, focus, or explicit visibility.
  • TableResizeHandle — Provide a keyboard-operable column resize handle that emits bounded resize requests.
  • TableSelectionCell — Select a row using a labelled native checkbox or radio control.
  • Tabs — Switch between related views with controlled selection and keyboard navigation.
  • TabList — Group Tabs with keyboard selection, a selection callback, and an option to reserve label width across selected states.
  • TabListProvider — Supply selection, keyboard, appearance, and tab-registration behavior to composed TabList and Tab descendants.
  • Tab — Represent one selectable view in a TabList with optional leading icon content.
  • TabPanel — Contain the content associated with one Tab.
  • TagPicker — Search, choose, and remove multiple values with keyboard and native form support.
  • TagPickerButton — Provide a button-only TagPicker trigger. In framework-neutral markup, place a native button in the picker’s button slot.
  • TagPickerControl — Compose selected tags, the picker input, and secondary control actions.
  • TagPickerGroup — Render consumer-owned selected tags inside the TagPicker control.
  • TagPickerInput — Configure and observe the TagPicker search input.
  • TagPickerList — Compose a collection of TagPicker options in the picker popup.
  • TagPickerOptionGroup — Group TagPicker options under an accessible label.
  • TagPickerOption — Define a selectable or disabled result inside a TagPicker.
  • Tag — Represent a selected value or status with theme-derived appearance and optional dismissal.
  • TagGroup — Arrange related tags as a labelled horizontal or vertical collection.
  • InteractionTag — Compose a selectable primary action and optional dismiss action in a theme-derived tag.
  • InteractionTagPrimary — Provide the primary button and optional media, icon, and secondary text for InteractionTag.
  • InteractionTagSecondary — Provide the accessible secondary dismiss button for InteractionTag.
  • TeachingPopover — Guide users through a keyboard-contained help surface anchored to a trigger.
  • TeachingPopoverTrigger — Provide the trigger composition part for TeachingPopover.
  • TeachingPopoverSurface — Group the content shown inside a TeachingPopover.
  • TeachingPopoverHeader — Show a heading area and dismiss action for guided help.
  • TeachingPopoverTitle — Give a teaching surface its visible heading.
  • TeachingPopoverBody — Present instructional text and optional media.
  • TeachingPopoverFooter — Arrange primary and secondary actions below teaching content.
  • TeachingPopoverCarousel — Present a controlled or uncontrolled sequence of guided steps.
  • TeachingPopoverCarouselCard — Define one keyed step in a teaching carousel.
  • TeachingPopoverCarouselFooter — Place navigation actions and progress in a teaching carousel.
  • TeachingPopoverCarouselFooterButton — Move between tutorial steps or finish and dismiss the tour.
  • TeachingPopoverCarouselNav — Group direct navigation controls for tutorial steps.
  • TeachingPopoverCarouselNavButton — Jump directly to a keyed tutorial step.
  • TeachingPopoverCarouselPageCount — Announce the current step and total count to assistive technology.
  • Text — Set consistent, theme-aware type size, weight, font, alignment, emphasis, and semantic element.
  • Body1 — Fluent Body1 typography preset (base 300, regular). Use the custom element with size=300 for framework-neutral composition.
  • Body1Strong — Fluent Body1Strong typography preset (base 300, semibold).
  • Body1Stronger — Fluent Body1Stronger typography preset (base 300, bold).
  • Body2 — Fluent Body2 typography preset (base 400, regular).
  • Caption1 — Fluent Caption1 typography preset (base 200, regular).
  • Caption1Strong — Fluent Caption1Strong typography preset (base 200, semibold).
  • Caption1Stronger — Fluent Caption1Stronger typography preset (base 200, bold).
  • Caption2 — Fluent Caption2 typography preset (base 100, regular).
  • Caption2Strong — Fluent Caption2Strong typography preset (base 100, semibold).
  • Display — Fluent Display typography preset (hero 1000, semibold).
  • LargeTitle — Fluent LargeTitle typography preset (hero 900, semibold).
  • Subtitle1 — Fluent Subtitle1 typography preset (base 500, semibold).
  • Subtitle2 — Fluent Subtitle2 typography preset (base 400, semibold).
  • Subtitle2Stronger — Fluent Subtitle2Stronger typography preset (base 400, bold).
  • Title1 — Fluent Title1 typography preset (hero 800, semibold).
  • Title2 — Fluent Title2 typography preset (hero 700, semibold).
  • Title3 — Fluent Title3 typography preset (base 600, semibold).
  • TextArea — Edit multi-line text with controlled or default values, Fluent appearances and sizes, native resize control, and change callbacks.
  • Toast — Announce brief, dismissible feedback with intent-based live politeness, priority scheduling, and a three-second timeout that continues while hovered or the window is unfocused.
  • ToastBody — Compose toast message content with an optional secondary subtitle.
  • ToastFooter — Place one or more actions in the toast action region.
  • ToastTitle — Compose a toast title with intent media and a trailing title action.
  • ToastTrigger — Make a toast child dismiss its toast when activated, with optional button semantics for non-button elements.
  • Toaster — Host a bounded notification region with priority-queued, timed, focus-aware Toasts, keyboard movement and dismissal, and the useToastController API.
  • Checkbox — Select independent values with unchecked, checked, or mixed state; choose square/circular shape, medium/large size, and logical label placement. Checkbox and Switch integrate with native forms, required validity, disabled fieldsets, and reset.
  • Switch — Change a binary setting with an explicit label, small or medium sizing, logical label placement, native form participation, and optional keyboard-focusable disabled state.
  • Toolbar — Group related commands with one tab stop, arrow-key navigation, optional size, and controlled or default named radio selections.
  • ToolbarRadioGroup — Group mutually exclusive toolbar radio commands under an accessible radiogroup name.
  • ToolbarRadioButton — Selectable toolbar radio command associated with a named checked-value set.
  • ToolbarDivider — Theme-derived non-interactive divider within a toolbar.
  • ToolbarGroup — Group related toolbar commands under an optional accessible name; controls remain part of the parent toolbar’s single roving tab sequence.
  • ToolbarSeparator — Theme-derived non-interactive separator that reports the orientation matching its parent Toolbar layout.
  • Tooltip — Provide delayed hover/focus help with label, description, or inaccessible relationships; portal the surface to a custom mountNode while keeping the trigger in place; supports theme appearances, controlled visibility, arrows, and Fluent-compatible fallback, boundary, sizing, target, offset, and positioning-ref options.
  • Tree — Browse nested folders or navigation nodes with hierarchy semantics and RTL-aware keys.
  • TreeItemLayout — Compose the content, icons, aside, and actions for a TreeItem while keeping expansion and selection controls in the tree engine.
  • TreeItemPersonaLayout — Compose a person-style TreeItem with media, primary and secondary text, aside, and actions.
  • TreeItem — Declare a leaf or branch in a composable Tree; the Tree owns rendering, hierarchy, focus, selection, and expansion.
  • FlatTreeItem — Declare one flat Tree record with a parent value and explicit hierarchy metadata.
  • FlatTree — Build a hierarchical accessible Tree from flat items linked by parentValue.
  • ViewCard — Present a document, person, task, approval, or list item with replaceable fields and actions.
  • VirtualList — Render large local or asynchronously range-loaded collections with bounded horizontal or vertical viewport rendering, fixed or measured item sizes, and accessible list position metadata.
  • Virtualizer — Render large horizontal or vertical collections through a bounded accessible viewport, or use browser-window scrolling for vertical page-flow lists, with fixed or measured item sizes, index-based rendering, and imperative scrolling.
  • VirtualizerScrollView — Compatibility view for Fluent’s legacy fixed-size virtualizer, with a responsive render window, accessible list positions, imperative scrolling, and optional scroll snapping.
  • VirtualizerScrollViewDynamic — Compatibility view for Fluent’s legacy measured virtualizer, with variable item sizes, responsive rendering, accessible list positions, imperative scrolling, and optional scroll snapping.
