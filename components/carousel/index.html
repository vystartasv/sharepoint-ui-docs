Carousel

Carousel

Section titled “Carousel”

Compose direct or grouped CarouselCard slides with localized navigation, optional autoplay, numeric or responsive page groups, drag interaction, and theme-aware motion.

React export: CarouselCustom element: <spui-carousel>

Slots: slides (direct or CarouselViewport > CarouselSlider > CarouselCard), navigation slot (CarouselNavContainer or CarouselNav)

Callbacks: onIndexChange, onActiveIndexChange

Styling: SharePointUIProvider tokens, CSS custom properties, host className/style, named ::part hooks, slideWidth or --spui-carousel-slide-width for fluid per-slide sizing, align, appearance, motion and motionDuration props; slideWidth or --spui-carousel-slide-width for fluid sizing, motion accepts slide attraction physics: { kind: "slide", duration?: number }; duration follows Embla’s 20–60 recommendation

React API signature
